# 小苗實驗記錄紙

> 分類：資料管理系統／研究工作項目／小苗實驗

## 一、檔案格式

- 輸出 Excel `.xlsx`，不產生 PDF。
- 檔名格式：`小苗試驗紀錄YYYYMM紀錄紙.xlsx`。
- `YYYYMM` 由調查批次的 `survey_period` 產生，不由下載當天日期產生。
- 例如 `survey_period = 2026-10` 時，檔名為 `小苗試驗紀錄202610紀錄紙.xlsx`。

## 二、資料來源與排序

- 記錄紙由已建立的調查批次個體名單產生。
- G 結束追蹤的個體預設不列入。
- 依 `survey_order` 排列，因此不同 Plot 會按照實際調查順序依序出現。
- 記錄紙與 Handsontable 必須使用同一批名單，不可各自重新查詢產生。
- 同一批次可重複下載相同記錄紙；下載不重新建立或更新名單。

## 三、欄位格式

記錄紙依目前紙本範例顯示：

| 欄位 | 初始內容 |
| --- | --- |
| Plot | 樣區編號 |
| No | 小苗編號 |
| sp. | 物種名稱 |
| 高度（前次） | 前一次調查高度 |
| 高度（本次） | 空白，供現場填寫 |
| 葉片（前次） | 前一次調查葉片數 |
| 葉片（本次） | 空白，供現場填寫 |
| 狀態 | 前一次調查 Status |
| 備註 | 前一次調查備註 |

記錄紙不顯示子葉數，也不另外增加「子葉數」欄位。

## 四、與輸入批次的關係

1. 系統建立下一個調查年月及調查批次。
2. 系統固定該批次需調查的個體及順序。
3. 使用者可下載 Excel 記錄紙。
4. 使用者可開始或繼續 Handsontable 輸入。
5. 批次完成前不能建立下一個月份，但可以重複下載目前批次的記錄紙。

目前輸出採直向 A4、標題列凍結與篩選、各欄框線，列印時重複第一列並縮放為一頁寬。欄位排列依提供的 Excel 範例輸出。

列印頁首頁尾：

- 頁首左側：地被小苗試驗 YYYY-MM，年月取自調查批次，14 級粗體。
- 頁首右側：調查日期____________________________。
- 頁尾右側：目前頁／總頁數，例如 `1/5`。

表格文字使用 11 級微軟正黑體，標題列為粗體；各列高度在 Excel 內以 20 pt 儲存。
