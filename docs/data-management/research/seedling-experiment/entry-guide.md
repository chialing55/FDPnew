# 小苗實驗資料輸入注意事項

> 分類：資料管理系統／研究工作項目／小苗實驗

本文件記錄「小苗實驗資料輸入注意事項」頁面的研究專屬內容。頁面版型依[資料輸入注意事項共用格式](../../interface-specs/data-entry-notice.md)實作：上方為重要操作提醒，下方以獨立區塊依序說明共同操作、地被實驗第二期及溫室實驗。各區塊採上下排列，避免表格與說明因左右並排而過寬。

## 共同操作

1. 調查原則為每月一次，系統依目前調查月份顯示本期固定名單。
2. 開始輸入前先選擇實際調查日期；Date 不是資料輸入日期。
3. 系統依調查順序顯示處理或樣區及個體，不需另外選擇樣站。
4. Status 為 A 時輸入本次實際量測值。
5. Status 為 D 或 G 時，系統將適用的量測欄位自動帶入 `-4`。
6. D 表示下個月仍繼續調查；G 表示本次後結束追蹤。
7. 每個分組輸入後都要按「儲存」。系統逐筆檢查並儲存：正確資料會先儲存；錯誤資料不會儲存，修正後需再次儲存；長度留白的資料視為尚未輸入並跳過。
8. 所有個體儲存完成後，才能按「確認本月輸入完成」。系統檢查完成後自動建立下一個調查月份。

## 地被實驗第二期

1. 資料依樣區組分頁。
2. 欄位為 Date、Plot、Density、No.、Species、長度、子葉數、葉片數、Status 與備註。
3. 新一期預設 Status 為 A、子葉數為 0。
4. 前一期為 D 者，長度、子葉數、葉片數及 Status 預設為 `-4、-4、-4、D`。
5. 香楠子葉數必須為 0。
6. 黃杞子葉數最多為 2，且不可比前一次增加。
7. 經人工確認已為 G 的個體需要恢復追蹤時，可使用「G 復活」加入本期名單。

## 溫室實驗

1. 資料依 Treatment 分頁，Treatment 與個體皆依調查順序排列。
2. 欄位為 Date、Treatment、No.、Species、長度、葉片數、Status 與備註，不使用 Density 與子葉數。
3. 新一期預設 Status 為 A。
4. 前一期為 D 者，長度、葉片數及 Status 預設為 `-4、-4、D`。
5. 經人工確認已為 G 的個體需要恢復追蹤時，可使用「G 復活」加入本期名單。

## 維護原則

- 頁面只說明日常輸入需要知道的內容，不放置歷史資料匯入規則。
- 欄位、驗證或狀態流程異動時，應同步更新注意事項頁、本文件及[小苗實驗資料輸入](data-entry.md)。
- 完整資料表與特殊值定義以[小苗實驗資料說明](data-spec.md)為準。
