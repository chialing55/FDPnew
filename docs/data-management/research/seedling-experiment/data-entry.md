# 小苗實驗資料輸入
> 分類：資料管理系統／研究工作項目／小苗實驗

本文件說明小苗實驗日常調查的資料輸入介面與操作流程。資料表、狀態及量測值定義以[小苗實驗資料說明](data-spec.md)為準；表格共同行為依[Handsontable 資料輸入介面規範](../../interface-specs/handsontable.md)實作。

## 一、適用範圍

資料輸入頁分為：

- 地被實驗第二期。
- 溫室實驗。

地被實驗第一期已結束，不提供新的日常調查輸入。歷史資料仍可由資料檢視功能查詢。

## 二、調查批次

- 調查原則為每月一次。
- 系統以正式資料中最新的 `survey_period` 加一個月，產生下一個調查年月。
- 頁面標題格式為「YYYY 年 M 月 地被實驗第二期資料輸入」。
- 建立調查批次時固定本期應調查的個體名單與排序。
- 記錄紙與 Handsontable 必須使用同一批固定名單，不可各自重新查詢。
- 同一調查年月原則上使用同一調查日期；若不同 Plot 實際於不同日期完成，仍可在各列修改日期。
- 前一批尚未完成時，不建立下一個月份的批次。
- 所有個體完成輸入並按下「確認本月輸入完成」後，系統將本批次標示為 completed，並自動建立下一個月份的固定名單。

## 三、頁面資訊與開始輸入

開始輸入前顯示：

- 「請先詳閱 **資料輸入注意事項**」連結。
- 輸入者：由登入帳號取得。
- 輸入日期：由系統產生。
- 調查日期：初始留白，使用日期欄位選擇。
- 「開始輸入」按鈕。

選擇調查日期後，可將日期帶入本次尚未填寫的資料列；每列日期仍可個別修改。系統不得使用輸入日期代替實際調查日期。

## 四、個體名單與樣區組導覽

- 不要求使用者先選樣站。
- 系統依個體的 `survey_order` 排定 Plot 與個體順序；同一主樣區必須形成單一連續區段，才可合併顯示。
- `PM001-DC`、`PM001-DR` 等相同主編號歸為 `PM001` 樣區組；輸入畫面一次呈現一組，並提供前後組導覽，資料列仍保留完整 Plot。
- `survey_order` 只用於排序，不顯示為輸入欄位。
- 已有 `end_date` 的個體不加入新批次。
- `G` 代表結束追蹤，因此預設不再列入後續調查。
- 使用「G 復活」操作時，只能選擇目前樣區組內、最後狀態為 G 且尚未加入本期的個體；加入後依原 `survey_order` 排回表格。

## 五、Handsontable 欄位

表格欄位為：

| 欄位 | 編輯方式 | 說明 |
| --- | --- | --- |
| Date | 可編輯日期 | 實際調查日期 |
| Plot | 唯讀 | 樣區編號 |
| Density | 唯讀 | 樣區密度 |
| No. | 唯讀 | 小苗個體編號 |
| Species | 唯讀 | 香楠或黃杞 |
| 長度 | 可編輯數值 | 依狀態輸入實測值或識別值 |
| 子葉數 | 可編輯數值 | 第二期使用 |
| 葉片數 | 可編輯數值 | 依狀態輸入實測值或識別值 |
| Status | 下拉選單 | A、D、G |
| 備註 | 可編輯文字 | 必要時填寫 |

為避免表格過寬，輸入畫面不另外顯示上次長度、子葉數、葉片數與 Status。Plot、Density、No.、Species 雖為前端唯讀，後端儲存時仍須重新核對。

## 六、狀態與量測輸入

- 新一期尚未有資料時，Status 預設為 A，子葉數預設為 0；長度與葉片數留待輸入。
- 前一期最後狀態為 D 時，本期預設延續為 `-4、-4、-4、D`，調查者仍可依現況改為 A 或 G。
- A：輸入本次實際量測值。
- D：適用的量測欄位輸入 `-4`，個體下期仍繼續調查。
- G：適用的量測欄位輸入 `-4`，本次紀錄完成後結束追蹤。
- 補登 A：適用量測欄位輸入 `-1`，並由恢復追蹤流程設定 `is_backfilled = true`。
- 已完成資料的適用量測欄位不得留白。
- 香楠存活紀錄的子葉數固定為 0。
- 黃杞存活紀錄的子葉數最多為 2，且必須與上次相同或減少，不可增加。
- G 復活後輸入本期 A 實測值；末段連續 D／G 紀錄改為 `-1、-1、-1、A` 並標記 `is_backfilled = true`，個體恢復追蹤。

完整的死亡、結束與恢復追蹤規則見[小苗實驗資料說明](data-spec.md)。

## 七、Handsontable 套用規則

本介面使用新的共用 Handsontable 規範：

- 共用層管理 instance、分頁、完整 draft、異動狀態及錯誤定位。
- 切換樣區組前，先將畫面內容同步到完整 draft。
- 有未儲存內容時，不得直接離開或切換而遺失資料。
- 儲存失敗時保留所有輸入內容。
- 後端錯誤需定位到資料列及欄位，並切換至第一個錯誤儲存格。
- 儲存期間停用重複送出。

小苗的 A／D／G、量測識別值及恢復追蹤規則由小苗實驗專屬 Service 處理，不寫入 Handsontable 共用元件。

## 八、驗證與儲存

儲存時：

1. 由登入狀態取得操作者。
2. 重新查詢本批次與目前工作範圍。
3. 長度留白的資料視為尚未輸入，本次跳過，不驗證也不寫入。
4. 對已輸入長度的資料，逐筆核對 Plot、Density、No.、Species 等唯讀欄位。
5. 逐筆驗證日期、Status 及量測欄位組合。
6. 每一筆各自在獨立 database transaction 中寫入；單筆錯誤不回滾其他正確資料。
7. 錯誤資料保留於前端 draft 並定位欄位，供使用者修正後再次儲存。

本研究採逐筆成功模式。儲存結果須分別回報已寫入／更新筆數、因長度空白而跳過的筆數及錯誤資料；沒有異動也應明確提示。

每個樣區組是一次送出範圍，但資料以單筆為儲存單位。各組可分次完成；樣區組選單會標示已完成的組別，但不另外顯示以個體株數計算的進度條。

## 九、完成本期與建立下期

1. 所有批次個體皆已連結本期正式 record 後，才啟用「確認本月輸入完成」。
2. 確認時從資料庫重新逐筆檢查：record 與個體連結、調查年月、調查日期、長度、子葉數、葉片數、Status、A／D／G 量測組合及物種子葉規則。
3. 任一筆缺漏或不合規則時停止完成，並回報 Plot、No. 與錯誤原因；備註維持選填。
4. 全部通過後才將本批次狀態改為 completed，並記錄完成者與完成時間。
5. 依本期更新後的 end_date 排除 G 結束個體。
6. 自動建立下一個月份的 prepared 批次及固定名單。
7. 下一期記錄紙可立即於相關文件頁下載。

「確認本月輸入完成」只在最後一個樣區組顯示；若仍有未完成個體，按鈕維持停用並顯示剩餘條件。

## 十、記錄紙關係

- 建立調查批次後即可下載該批次記錄紙。
- 記錄紙可以重複下載，不因下載而重建個體名單。
- 開始輸入後仍可下載同一批記錄紙。
- 記錄紙格式及檔名規則見[小苗實驗記錄紙](record-paper.md)。
