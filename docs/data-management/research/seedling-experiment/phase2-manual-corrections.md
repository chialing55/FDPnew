### M819-1 缺漏補登

`PE001-DC / M819-1` 缺少 `2025-08-29` 紀錄，且當日其他 Plot 也找不到相同編號，因此不是 Plot 誤植。人工新增一筆補登資料：

```text

plot = PE001-DC
no = M819-1
species = 香楠
length = -1
cotyledon_count = -1
leaf_count = -1

```

整理程式只會在該筆不存在時新增，重複執行不會重複建立。正式匯入 records 時必須設定 `is_backfilled = true`。

判定方式：`PE001-DC` 在 `2025-08-29` 有其他小苗的調查資料，`M819-1` 本身在前一期 `2025-07-30` 與後一期 `2025-09-29` 皆有連續紀錄，因此判定為單株漏記，而非整個樣區未調查。目前第一、二期 cleaned 依各 Plot 的實際調查日期檢查後，除此筆已補登資料外，沒有其他個體中間缺期。

- 編號：`E308`
