# 資料檢視介面規範

> 分類：資料管理系統／介面規範

本文件定義後台工作項目的資料檢視格式與基本功能。新增資料檢視時，應先沿用本規範與既有共用元件，再依資料集增加必要欄位。

## 一、頁面結構

1. 資料檢視置於工作項目的「資料檢視」主活頁。
2. 同一工作項目包含多個資料集時，在內容區上方使用頁籤切換；切換後只查詢目前資料集。
3. 標題顯示「資料集名稱＋資料檢視」，並列出最新調查年月及目前篩選結果總筆數。
4. 表格上方顯示分頁控制；每頁預設 50 筆。
5. 無資料或篩選後無結果時，在表格內顯示明確的空資料訊息，不隱藏整個表格。

## 二、共通功能

- 分頁：上一頁、下一頁、指定頁碼、目前頁數與總頁數。
- 篩選：選項型欄位使用下拉選單；文字識別碼採前綴查詢；物種採包含查詢；數值欄位提供 `>`、`≧`、`=`、`≦`、`<`。
- 排序：只開放程式白名單內的欄位，避免直接接受任意 SQL 欄名。再次點擊同一欄位時切換升冪／降冪。
- 資料集切換：切換時清除上一資料集的篩選、頁碼與排序狀態，避免條件誤套。
- 調查批次辨識：跨調查年月時以較粗的上框線分隔。
- 載入回饋：Livewire 查詢期間顯示既有 loading spinner。

## 三、欄位與顯示原則

1. 表格原則上顯示正式資料表內容；若工作項目需要檢視暫存資料，應在該工作項目的文件中另行說明。
2. 日期欄位依調查方式顯示調查期及實際調查日期。
3. `NULL` 顯示空白，不自行轉成其他數值或狀態。
4. 長文字欄（例如備註）保留足夠寬度；整張表格超過畫面時由內容區水平捲動，不壓縮到無法閱讀。
5. 欄位名稱以使用者熟悉的調查表名稱為主，資料庫欄位只在工作項目的文件中對照。

## 四、共用元件

目前共用的 Blade partial：

- `livewire.partials.dataviewer-summary`：標題、最新調查期、筆數。
- `livewire.partials.dataviewer-pagination`：分頁控制。
- `livewire.partials.dataviewer-sortable-heading`：排序欄位標題與方向指示。
- `livewire.partials.dataviewer-styles`：資料檢視表格共通排序按鈕樣式。
- `livewire.partials.select-filter`：下拉選項篩選。
- `livewire.partials.datalist-filter`：可輸入文字的建議清單篩選。
- `livewire.partials.numeric-filter`：比較運算子與數值篩選。

資料表的 join、欄位與業務規則仍放在各自 Livewire Component；只有可跨工作項目穩定共用的畫面行為才抽成 partial，避免形成包含大量條件判斷的單一元件。

## 五、新工作項目檢查清單

- 使用正式資料來源，並限定工作項目／資料集 scope。
- count、資料列及篩選選項都使用相同 scope。
- 排序欄位採白名單。
- 大量資料使用資料庫分頁，不一次載入全部資料。
- 篩選或切換資料集後回到第 1 頁。
- `NULL`、空資料及載入中狀態均有一致呈現。
- 優先沿用上述 partial；新增通用行為時同步更新本文件。
