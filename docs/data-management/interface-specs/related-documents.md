# 相關文件頁面規範

> 分類：資料管理系統／介面規範

本文件定義後台工作項目的「相關文件」頁面共通結構。各調查的記錄紙欄位、版面與產生方式不同，不在本文件統一規定。

## 一、入口與頁籤

1. 「相關文件」放在工作項目第一個主頁籤。
2. 從工作選擇頁點入工作項目時，直接進入「相關文件」，不先顯示空白首頁或說明頁。
3. 目前頁籤沿用工作項目導覽列的 `now` 樣式。
4. 頁面內容使用既有的 `.flex.text_outbox` 排列一個或多個 `.text_box`。

## 二、文件方塊

調查說明、樣區圖、輸入檢查流程或下載功能各自使用獨立 `.text_box`，基本結構為：

1. `h2`：說明文件或功能名稱。
2. `hr`：分隔標題與操作區。
3. 內容：使用簡短說明、`ol`、`ul`、下載連結或該功能需要的控制項。

下載檔或外部文件在新分頁開啟。尚未完成的功能不可先套用其他調查的格式；可暫時顯示「格式確認後加入」。

## 三、記錄紙功能

新增記錄紙前，必須在該研究工作項目的文件中先確認：

- 紙張方向、分頁方式與每頁筆數。
- 欄位、欄寬及上次調查資料的呈現方式。
- 收錄哪些個體與排序規則。
- 是否需要自訂範圍或固定分段下載。
- 檔案格式及檔名。

在規格確認前，不以一般小苗、每木或其他調查的記錄紙推定新工作項目的格式。
