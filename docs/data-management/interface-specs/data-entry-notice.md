# 資料輸入注意事項共用格式

> 分類：資料管理系統／介面規範

本文件規範各研究「資料輸入注意事項」頁面的共同結構。研究專屬的欄位定義、狀態代碼及驗證規則應寫在各研究文件，不在本文件重複定義。

## 一、頁面目的

資料輸入注意事項提供調查人員在開始輸入前快速確認操作流程、欄位填法及特殊狀態。內容應以實際操作為主，避免放入資料庫結構、歷史匯入程序或只供開發者使用的實作細節。

## 二、共用結構

頁面依下列順序呈現：

1. 頁面標題：`研究名稱＋資料輸入注意事項`。
2. 重要提醒：列出儲存、完成調查及其他可能造成資料遺失的操作。
3. 共同操作：說明日期、導覽、儲存與完成流程。
4. 資料類型或研究分區：分別說明欄位、狀態與特殊驗證。

重要提醒應保持精簡，詳細規則放在下方對應區塊。

## 三、共用 Blade 版型

沿用既有小苗調查注意事項的 CSS class：

```blade
<div>
    <h2>研究名稱資料輸入注意事項</h2>

    <div class="note">
        <ul style="font-weight:800;">
            <li>重要操作提醒。</li>
        </ul>

        <div class="flex text_outbox" style="flex-direction:column;">
            <div class="text_box_note_out" style="width:100%;">
                <div class="text_box text_box_note">
                    <h2>區塊標題</h2>
                    <ol>
                        <li><b>欄位或操作</b>－說明內容。</li>
                    </ol>
                </div>
            </div>
        </div>
    </div>
</div>
```

使用的共用 class：

| Class | 用途 |
| --- | --- |
| `note` | 包住整份注意事項內容 |
| `text_outbox` | 管理內容區塊排列 |
| `text_box_note_out` | 每一個注意事項區塊的外層 |
| `text_box text_box_note` | 顯示有一致邊界、留白與標題的內容卡片 |
| `line` | 標示需要特別注意的短句；不可用於整段文字 |

## 四、版面規則

- 內容區塊預設上下排列，使用 `flex-direction: column`。
- `text_box_note_out` 使用 `width: 100%`，避免左右排列造成文字區塊過寬或欄位被壓縮。
- 同一區塊只說明一個主題；不同研究、不同資料類型應分成不同區塊。
- 頁面標題不放入 `text_box`，各分區標題放在 `text_box_note` 內。
- 操作順序使用有序清單；純粹並列的提醒才使用無序清單。
- 欄位名稱、按鈕名稱及狀態代碼使用粗體，特殊值使用反引號或粗體。
- 不另外建立研究專屬色彩與卡片樣式，優先沿用現有共用 class。

## 五、內容規則

注意事項至少應涵蓋：

1. 實際調查日期如何填寫。
2. 資料如何分組及切換。
3. 哪些欄位可輸入、哪些欄位唯讀。
4. 一般量測值與特殊狀態如何填寫。
5. 儲存、錯誤修正及完成調查的操作順序。
6. 會停止後續追蹤或改變名單的狀態。

頁面文字必須與實際系統行為一致。功能、欄位或驗證規則變更時，應同時更新：

- 注意事項頁面。
- 研究專屬資料輸入文件。
- 研究資料規格文件中受影響的規則。
