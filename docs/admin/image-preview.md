# 個人網站圖片與預覽

首圖前台與後台共用 `public/css/changyang.css` 的 Hero 樣式。後台以目前視窗寬度建立畫布，再將圖片、遮罩與文字一起等比縮小；圖片先以 `cover` 填滿框架，再套用放大倍率與位置。預覽對應目前視窗尺寸，其他裝置仍會依響應式版型裁切。

位置、倍率和高度儲存在設定中，不會因此裁切或另存原始圖片。

內容區塊沒有圖片時，只顯示文字編輯框；有圖片才顯示圖片調整與圖文預覽。移除圖片列後須儲存頁面，原始圖片檔案會保留。文字清單的圓點、編號與縮排由共用樣式定義。

相簿指定封面時會同時公開該照片；隱藏照片會取消其封面資格。沒有指定封面時，使用排序最前的公開照片。替代文字取自照片標題。

## Zotero 手動更新

兩個管理入口共用 `SyncZoteroPublicationsAction`。同步交由背景 queue 執行；再次開啟確認視窗可查看最近一次手動同步的進度或結果，視窗每五秒更新。重複排入同一工作會受唯一工作鎖限制，完成結果保留三十天。每月排程不屬於此手動結果紀錄。

背景工作逾時為 300 秒，database queue 的 `retry_after` 為 360 秒，避免工作尚未逾時即被再次取出。部署更新後應讓 queue worker 重新載入程式。

執行 Artisan 快取命令時使用網站執行身分 `www-data`，避免產生網站無法寫入的 root 擁有檔案。
